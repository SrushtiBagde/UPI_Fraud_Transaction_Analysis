# UPI Fraud Transaction Analysis Dashboard

##  Project Overview

This project analyzes UPI transaction data to identify fraud patterns and provide actionable insights through an interactive Power BI dashboard. The dataset was cleaned, explored, and analyzed using Python, and the final dashboard was built in Power BI.

---

##  Objectives

* Clean and preprocess UPI transaction data.
* Perform Exploratory Data Analysis (EDA).
* Identify fraud patterns and trends.
* Create meaningful visualizations.
* Build an interactive Power BI dashboard.

---

##  Dashboard Features

* Total Transactions
* Fraud Transactions

* Fraud by Merchant Category

* Fraud by Device Type
* Fraud by Network Type
* Fraud Trend by Hour

  * Timestamp

---

##  Data Analysis Process

1. Imported the dataset into Python.
2. Cleaned and preprocessed the data.
3. Handled missing values and duplicates.
4. Converted data types.
5. Performed Exploratory Data Analysis (EDA).
6. Created new features for analysis.
7. Exported the cleaned dataset.
8. Built an interactive Power BI dashboard.

---

##  Key Insights

* Identified transaction categories with higher fraud occurrences.
* Analyzed fraud distribution across different states.
* Examined fraud patterns by device type and network type.
* Observed fraud trends by transaction hour.
* Compared fraud distribution across transaction amount categories.
